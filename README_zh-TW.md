# MSW 五雷印浮水印製作工具

[English](README.md)

MSW 五雷印是一款 Windows 桌面防盜浮水印工具，可為圖片加入可調整的識別標記，協助創作者辨識與保護自己的作品。

目前發佈版本：**v1.1.1**

[下載最新版本](https://github.com/duoduo-88/MSW-5-Thunder-Stamper/releases/latest)

## 主要特色

- 依定位圖與紅點配置標記
- 支援內建或外部定位圖，以及紅點連線
- 支援 PNG 字形與系統字型
- 可調整的隨機化視覺效果
- 平行處理與透明 PNG 輸出
- 繁體中文與英文介面
- 深色介面與多種預覽背景

## 使用原則

本專案用於作品來源標記與防盜用途；可見浮水印並不等同於密碼學上的所有權證明。請只處理自己擁有或已取得授權的素材。

為降低未授權轉售者濫用，本專案刻意不提供詳細操作與打包說明。
