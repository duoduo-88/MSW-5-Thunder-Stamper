# MSW 五雷印浮水印製作工具

[English](README.md)

MSW 5 Thunder Stamper 是 Windows 桌面浮水印工具，可依紅點定位圖指定的位置重複放置文字或圖像字元防偽標記。程式支援內建定位圖、選用外部 `origin.png`、自訂 PNG 字元、系統字體、隨機視覺效果、多進程運算及透明 PNG 匯出。

目前發佈版本：**v1.0.1**

[下載 Windows 發佈包](https://github.com/duoduo-88/MSW-5-Thunder-Stamper/releases/latest)

## 主要功能

- 在定位圖偵測到的每個位置放置指定代碼。
- 內建紅點定位圖，也可改用外部 `origin.png`。
- 預設會將相連的紅色像素合併成單一放置位置。
- 可使用自訂英數 PNG 字元，或選擇 `.ttf`／`.otf` 系統字體。
- 系統字體模式支援任意長度文字。
- 可調整縮放、字體透明度、字距、整體與單字抖動及 X／Y 偏移。
- 可加入字元噪點、邊緣羽化、彩色光暈及光暈噪點。
- 大量定位點可使用多進程及可調整的分批大小處理。
- 支援深灰、白色、50% 灰、透明棋盤格或自訂預覽背景；預覽背景不會寫入輸出。
- 可將合成結果匯出為 PNG。

## 系統需求

### Windows 發佈包

- Windows 10 或 11
- 可解壓縮 `.7z` 的軟體
- 足以容納所選圖片及多進程工作的記憶體

解壓縮最新版發佈包後執行其中的 EXE，不必另外安裝 Python。

### Python 原始碼

- 建議使用 Python 3.10 或更新版本
- PySide6
- Pillow

安裝依賴：

```powershell
python -m pip install PySide6 Pillow
```

執行目前原始碼：

```powershell
python "MSW 5 Thunder Stamper v1.0.1 .py"
```

## 基本操作流程

1. 載入要加入標記的 PNG、JPEG 或 BMP 圖片。
2. 輸入所需代碼或文字。
3. 選擇定位圖模式：
   - 保持「優先使用內建紅點」啟用，使用內建且會配合載入圖片縮放的定位圖。
   - 關閉此選項後，程式會在載入圖片所在資料夾或程式資料夾尋找 `origin.png`。
4. 選擇文字渲染方式：
   - PNG 字元模式會從 `glyphs`、載入圖片資料夾或程式資料夾讀取字元圖。
   - 系統字體模式會使用選定字體，必要時需手動指定 `.ttf` 或 `.otf` 檔案。
5. 調整位置、透明度、噪點、羽化、光暈、CPU 核心及分批設定。
6. 點擊「生成水印」並檢查預覽。
7. 點擊「另存PNG」匯出結果。

## 自訂 PNG 字元

程式啟動時會建立 `glyphs` 資料夾。在 PNG 字元模式中：

- 檔案查找支援英文字母與數字。
- 檔名使用大寫，例如 `A.png`、`B.png`、`7.png`。
- 輸入字元會轉換成大寫後查找。
- 找不到對應字元時會顯示打叉的替代方框。
- 建議使用具有透明度的 RGBA PNG。

需要區分大小寫、空格、標點或其他 Unicode 字元時，請改用系統字體模式。

## 定位圖

程式會偵測定位圖中的紅色像素，並在對應座標附近放置代碼。啟用「合併近鄰紅點」時，相連的紅色像素會視為一個區塊，避免單一紅點產生大量重疊標記。外部 `origin.png` 尺寸不同時會配合載入圖片縮放。

## 隱私

目前原始碼只會讀寫本機圖片與字體檔案，不包含上傳、網路或遙測用戶端。

## 限制

- 輸出效果取決於定位圖、字體或字元圖品質及所選參數。
- PNG 字元模式只查找英數檔名；不支援或缺少的字元會使用替代方框。
- 系統字體檔案自動尋找可能失敗，此時需手動選擇 `.ttf` 或 `.otf`。
- 大量定位點、大尺寸圖片、多個工作進程及複雜光暈可能大量占用記憶體與處理時間。
- 本工具產生的是視覺標記，不提供密碼學簽章或所有權證明。
