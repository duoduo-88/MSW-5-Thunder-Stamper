# MSW 5 Thunder Stamper

[繁體中文](README_zh-TW.md)

MSW 5 Thunder Stamper is a Windows desktop tool for adding configurable authenticity marks to images. It is intended to help creators identify and protect their own work.

Current release: **v1.1.1**

[Download the latest release](https://github.com/duoduo-88/MSW-5-Thunder-Stamper/releases/latest)

## Highlights

- Marker-map and red-point based placement
- Embedded or external marker maps, with optional point connections
- PNG glyphs and system-font rendering
- Configurable randomized visual effects
- Parallel rendering and transparent PNG output
- Traditional Chinese and English interface
- Dark interface with multiple preview backgrounds

## Responsible use

This project is designed for provenance marking and anti-theft use. A visible mark is not cryptographic proof of ownership. Use it only with assets you own or are authorized to process.

To reduce misuse by unauthorized resellers, this repository intentionally omits detailed operating and packaging instructions.
